# 极简模式（minimal）

> Agent 模式（preset） · 官方 Agent 模式 · 默认关闭（需手动启用）

## 这个插件在干什么

仅提供持久 bash 与 str_replace_editor 两个工具的极简编码 Agent：固定提示词、双工具、无上下文压缩。

## 解决什么问题

完整工具集会引入注意力分散和误操作面；只需要一个稳定的 shell 加精确文本编辑时，工具越少越不容易出错。

## 推荐使用人群

任务边界清晰、偏好最小工具面、希望把误操作风险压到最低的开发者；也适合作为自建 preset 的起点。
