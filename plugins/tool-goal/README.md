# 目标工具（tool-goal）

> 工具 · 计划与目标 · 默认启用

## 这个插件在干什么

为 Agent 提供同一会话的目标工具（create_goal / update_goal / get_goal），带执行期权限校验，跨轮跟踪长期目标。

## 解决什么问题

长目标需要跨多轮持续跟踪，没有目标工具时模型会迷失方向或忘记初衷。

## 推荐使用人群

需要长周期目标推进、希望目标状态可查询可更新的用户。
