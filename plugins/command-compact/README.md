# 「/compact」命令（command-compact）

> 系统组件 · 上下文与压缩 · 默认启用

## 这个插件在干什么

面向用户的显式会话压缩斜杠命令：由用户主动触发一次上下文压缩。

## 解决什么问题

自动压缩的时机不一定符合用户预期；想手动控制压缩时机时缺一个明确的命令入口。

## 推荐使用人群

长会话用户；希望主动管理上下文、控制成本的用户。
