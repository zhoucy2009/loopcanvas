# 精确文本编辑（tool-str-replace-editor）

> 工具 · 文件与编辑 · 默认启用

## 这个插件在干什么

提供查看、创建、字面量替换与按行插入工具，要求精确匹配原文，避免模糊改写。

## 解决什么问题

整文件重写或模糊编辑会误改多处相似文本、产生不可控 diff；需要精确到字面量匹配的编辑方式。

## 推荐使用人群

追求精确编辑、希望 diff 干净可审查的开发者；也是极简模式的核心编辑工具。
