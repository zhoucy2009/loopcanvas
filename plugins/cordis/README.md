# 创造模式（cordis）

> Agent 模式（preset） · 官方 Agent 模式 · 默认关闭（需手动启用）

## 这个插件在干什么

用于创建自定义 Agent preset：具备标准模式全部能力，并提供运行时检查、插件实验和 preset 创作指导。

## 解决什么问题

想定制专属 Agent 需要理解 dsh 的 Cordis 组合机制，但缺少安全的实验环境和创作指引；直接改安装目录有破坏风险。

## 推荐使用人群

希望打造专属 Agent 模式、编写或实验插件的高级用户。该模式具备运行时操作能力，请按 shell 访问权限对待。
