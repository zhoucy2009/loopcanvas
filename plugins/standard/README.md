# 标准模式（standard）

> Agent 模式（preset） · 官方 Agent 模式 · 默认启用

## 这个插件在干什么

功能完整的编码 Agent：文件编辑、Shell、文件与网页检索、Skills、计划、目标、子代理和工作流一应俱全。

## 解决什么问题

复杂任务需要读代码、改文件、跑命令、查资料、委派子任务等多种能力配合，单工具 Agent 无法高效完成。

## 推荐使用人群

大多数日常开发与交付场景的用户；dsh 官方默认 Agent 模式。
