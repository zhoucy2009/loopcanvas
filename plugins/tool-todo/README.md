# 任务清单工具（tool-todo）

> 工具 · 执行与控制 · 默认启用

## 这个插件在干什么

为 Agent 提供 todo_write 任务清单工具，基于事件溯源的会话日志维护任务进度，支持并行进行中的任务。

## 解决什么问题

多步骤任务容易丢失进度和当前焦点；没有任务清单时模型和用户都看不清还剩什么。

## 推荐使用人群

多步骤、长任务场景的用户；需要随时确认进度的协作场景。
