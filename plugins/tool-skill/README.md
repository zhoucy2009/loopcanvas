# 技能加载工具（tool-skill）

> 工具 · 检索与信息 · 默认启用

## 这个插件在干什么

为 Agent 提供技能目录与加载器：按需加载 SKILL.md 技能，把可复用经验变成可调用的能力。

## 解决什么问题

把可复用经验写成技能后，需要被模型发现并按需加载；否则技能只能堆在上下文里浪费 token。

## 推荐使用人群

使用 Skills 复用工作流、希望沉淀团队经验的用户。
