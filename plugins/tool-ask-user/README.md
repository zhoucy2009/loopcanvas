# 询问用户（tool-ask-user）

> 工具 · 执行与控制 · 默认启用

## 这个插件在干什么

为 Agent 提供 ask_user_question 工具：在执行过程中向用户提问，确认选择或补齐缺失信息。

## 解决什么问题

需求有歧义、关键选择影响走向时，模型靠猜会跑偏；需要停下来问用户而不是假设。

## 推荐使用人群

所有用户；重视人机协作、希望关键决策由人拍板的场景。
