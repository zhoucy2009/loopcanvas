# 文件搜索工具（tool-fs-search）

> 工具 · 文件与编辑 · 默认启用

## 这个插件在干什么

为 Agent 提供文件发现工具（glob、grep），基于打包的 ripgrep 二进制，快速定位路径与内容匹配。

## 解决什么问题

大型代码库里手工翻找文件或匹配内容几乎不可行；需要快速、可复现的路径与全文搜索。

## 推荐使用人群

大型仓库、需要跨文件检索与重构定位的用户。
