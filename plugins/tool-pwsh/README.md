# PowerShell 命令执行（tool-pwsh）

> 工具 · Shell 与命令 · 默认启用

## 这个插件在干什么

Windows 平台上的 pwsh 工具：通过同一命令执行缝运行 PowerShell 命令并返回输出。

## 解决什么问题

非 Windows 平台使用 bash，而 Windows 上需要 PowerShell 才能执行命令；平台差异需要自动适配。

## 推荐使用人群

Windows 用户；在 Windows 上替代 bash 工具。
