# 四精灵工作状态

胶囊位于工作台右上角，执行区位于左侧。精灵使用本地 SVG 和 CSS 绘制，无额外图片、动画库或模型调用。

| 颜色 | 职责 | 进入执行区的依据 |
| --- | --- | --- |
| 紫色 | 接收需求 | 提交提示词并向规划请求交接；不是额外的大模型调用 |
| 绿色 | 计划 | 规划 runner 的真实调用 |
| 黄色 | 执行 | 单步、并行节点或连续项目执行 runner 的真实调用 |
| 红色 | 审核 | 步骤审核及最终审核 runner 的真实调用 |

- 每个需求有独立的四位精灵，只统计当前窗口选中项目的工作。其他窗口或项目正在执行，不会占用新需求的精灵；未选中项目时也不会汇总全局工作。
- 点击“＋ 新需求”或说“开一个新需求”，创建成功并切换到新项目后，四位新精灵一起跑入胶囊。点击/说“集合”只召集当前需求的空闲精灵。已有工作不会被清空、暂停或取消。
- 当前角色在胶囊里时才跳入；已经在执行区时，状态轮询、同色第二项工作和页面模式切换不会重复入场。
- 每份真实调用独立登记与释放。成功、异常退出均在 finally 释放；同一项目中同色有其他工作时继续留守，执行和审核可同时展示。后台项目的完成回调只释放自己的工作。
- 切换项目时取消旧项目尚未完成的动画，直接显示新选中项目的位置；切回仍在执行的旧项目时恢复它的工作状态，不重复播放入场动画。
- 紫色需求交接短于入场动画时，会完成跳入再返回，动画不阻塞网络或 Agent 工作。
- 集合约 480ms、跨区跳跃约 560ms，是用户明确要求的角色迁移动效；不循环、不持续弹跳。系统“减少动态效果”启用后只做 100ms 淡入；窗口缩放、滚动及不可见页面不播放跨区动画。
- `/api/agents/presence` 返回调用编号、角色、项目编号及开始时间，不包含提示词、输出、录音或凭据。连接中断时保留最后状态，并禁止以“集合”把未知状态当作空闲。

原生免点击唤醒已增加“集合”“开一个新需求”，通过原有的一次性唤醒事件交给网页。网页语音也支持这些指令。旧服务需在没有任务运行时重启以加载新事件白名单与工作状态接口。

## 验证

`cd web && npm test` 包含真实 runner 生命周期、按项目隔离、执行中开新需求、切回恢复、过期动画回调、同色并发、不同角色并行、快速交接、重复刷新不重播、减少动态效果和语音入口测试。

`node Scripts/preview-agent-sprites.mjs` 在 `http://127.0.0.1:4327` 提供独立视觉验证页。它使用真实精灵渲染器，但所有工作都是明确标注的测试数据，不调用 Agent、不读取或修改用户项目。
