# 工作流补证、审核与恢复（2026-09-07）

本次修改来自 9 月 5 日仅通过网页鼠标、键盘进行的工作流设计与执行测试。

## 已补齐

- 新规划保存完整原始要求、能力检查时间、工具可用性和人工参与提示。新建双视频规划加入说话人确认（涉及人物身份时）、合成前独立审核、观看成片确认。明确声明两个必需输入。
- 人工确认 / 补充证据节点：持久化等待，不调用模型代替人确认。可以打开本次输入、查看转写时间片段、填写依据、添加说话人与起止秒数、上传证据文件或填写路径。
- 证据提交校验本次等待凭据、所有输入路径、证据文件可读性、标注格式和明确确认。保存为 user-confirmed 来源，关联运行、节点、时间与实际输入；不冒充自动验证。可下载人工核验记录。
- 独立审核节点：单独 reviewer 调用、只读边界和结构化逐项结论。只有所有审核项都有标准、通过结论和证据时才放行；审核不能改全局变量。失败报告同样留档。
- 缺证据等待补充；格式/超时类只读分析错误可以重试；语义不合格、人工拒绝或有外部写入风险的错误不提供盲目重跑。恢复保留已完成节点、产物和原始失败日志。人工拒绝停止下游。
- 常用分析参数直接用表单编辑；高级 JSON 仍可使用。按上游节点名称和输出类型绑定参数，无需手填节点 UUID。
- 运行列表按箭头依赖顺序显示，画布支持按执行顺序整理，连接操作保留起点、终点和条件。
- 恢复接口立即返回已有产物下载链接。历史运行继续刷新；补证输入期间不重建表单。修复工具目录慢加载清掉已打开历史的情况。
- 服务重启造成的令牌失效只在服务端明确拒绝且尚未执行请求时自动刷新并重试一次；不自动重放网络失败或普通 403 的写请求。
- 窄屏取消顶部角色动画占位和固定底部统计遮挡；补证表单使用两列标注字段。

## 使用和边界

新建工作流时选择“人工确认 / 补充证据”或“独立审核”，逐项填写验收要求并连入执行顺序。自然语言规划仍是需要检查的草稿。常用内建媒体参数已有表单，其他工具的复杂嵌套参数仍在高级 JSON 中编辑。

旧工作流和运行快照不自动重写。旧的缺说话人证据分析失败可以补证恢复，但原有 output 节点不会自动升级为独立审核；要采用新设计，请新建规划或编辑模板后创建新的需求。

本次没有增加可靠的自动人物识别，也没有证明所有视频的幽默效果或整体叙事达到生产标准。说话人和成片声画检查仍需要真实人工证据；新增机制负责把缺口显式阻断、留档和恢复。
