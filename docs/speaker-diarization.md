# 本机声音分组与人物确认

工作流工具 `local_speaker_diarize` 根据声音特征输出匿名说话人、时间范围和代表性试听音频。人物姓名由用户填写；多个声音组填写同一姓名即可批量合并归属。未命名及多人重叠片段保留待确认，个别错误可用人工时间范围标注纠正。

新规划的多人素材分析流程在转写后加入声音分组和人工确认。旧运行停在补充证据时，也可在「自动区分说话人」中选择输入，自动估计人数或指定 1–32 人，生成试听并确认后继续，不重跑已经完成的转写。

姓名映射与声音分组版本、原始输入文件绑定。重新分组会清空旧映射；文件改变或分组版本过期时拒绝提交。日志和人工确认记录随本次运行保存。取消声音分组不会丢弃原工作流等待补充的状态。

## 开源组件

- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 1.13.7，独立 Python 环境，NumPy 2.2.6。
- [官方说话人分离模型与示例](https://k2-fsa.github.io/sherpa/onnx/speaker-diarization/models.html)：pyannote segmentation 3.0 ONNX + 中文 3D-Speaker ERes2Net embedding。
- 音轨转换使用 macOS 自带工具。首次下载运行组件及约 47 MB 模型，模型固定来源并校验 SHA-256；后续声音分析在本机进行，不上传音视频。

模型和独立环境位于应用数据目录的 `workflow-tools/speaker-diarization-v1`。首次准备失败会保留具体错误，可重试。当前音轨转换实现限 macOS。

## 验证记录（2026-09-07）

- 官方中文四人样例：默认阈值 0.9 自动分出 4 组；指定 4 人也能完成。56.9 秒音频处理约 3 秒，耗时取决于机器。
- 浏览器实际执行：声音分组 → 试听 → 填入四个测试标签 → 提交人工记录 → 完成；10 个时间范围正确写入记录。测试标签不代表真实人物身份。
- 试听接口支持 WAV 和 HTTP Range；实际播放按钮进入播放状态。
- 正式安装版中，9 月 7 日当前素材运行已生成 14 组、23 个试听片段，等待用户确认姓名；有 9 个重叠语音片段保留待确认。
- 320px 与 200% 放大时分组表单无横向溢出，键盘焦点可见，减少动态效果设置下无新增动画；浏览器未出现脚本错误。
- 用户已有相声素材：自动模式分出 15 组，存在过度分组，尚未逐段人工审计。声音变化、短回应、笑声和重叠发声会影响结果。已知人数时可指定人数重新分组，也可合并同人分组；不能把分组数量当成确定人数。
- 回归测试 285 项：284 通过、1 跳过。包含多人物映射、同名合并、忽略未命名和重叠、手工纠错、最新映射替换旧映射，以及旧运行补充分组后仅恢复分析步骤。

自动分组本身不证明人物身份。转写段只在已确认人物覆盖至少 75% 时间、其他人物覆盖不足 15% 时附上姓名，其余标记不确定；这里的覆盖率是时间覆盖比例，不是身份识别概率。
